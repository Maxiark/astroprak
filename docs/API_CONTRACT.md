# Спецификация API ядра Astrosite (v1.0.1)

Базовый путь: `/api`[cite: 4]

## 1. Публичные маршруты

### `GET /api/me`
Возвращает идентификатор пользователя и открытый код восстановления сессии:[cite: 4]
* **Ответ `200 OK`:**[cite: 4]
  ```json
  {
    "user_id": 1,
    "recovery_code": "a1b2c3d4e5f6789012345678abcdef01"
  }

```

### `POST /api/restore`

Переключает текущую сессию браузера на переданный код восстановления:

* **Тело запроса:** `{"key": "a1b2c3d4e5f6789012345678abcdef01"}`

* **Ответ `200 OK`:** `{"status": "ok", "message": "Сессия восстановлена"}`


### `GET /api/tasks`

Возвращает список всех проверенных активных манифестов из директории `/data/tasks/` (за исключением помеченных `"hidden": true`).

### `POST /api/attempts`

Возвращает активную незавершённую попытку либо генерирует новую, если предыдущая сдана или отсутствует:

* **Query-параметры:** `task_id` (обязательный), `seed` (опциональный целое число).


* **Логика идемпотентности:** Если в базе найдена запись `user_id = me AND task_id = task_id AND submitted_at IS NULL`, сервер возвращает её с ранее сохранённым черновиком ответов.
* **Ответ `200 OK`:**

```json
{
  "attempt_id": "42",
  "task": { ... },
  "answers": { "current_step": 2, "initial_m": 10 },
  "submitted": false
}

```



### `PATCH /api/attempts/{attempt_id}/answers`

Фоновое сохранение промежуточного черновика ответов (вызывается фронтендом с debounce при получении ответов от виджета):

* **Тело запроса:**
```json
{
  "answers": {
    "current_step": 3,
    "initial_m": 10,
    "model_type": "Экспоненциальное",
    "h_val": 0.22,
    "n0_val": 200
  }
}

```


* **Ответ `200 OK`:** `{"status": "ok"}`

### `POST /api/attempts/{attempt_id}/events`

Записывает пакет действий пользователя в журнал аудита:

* **Тело запроса:**

```json
{
  "events": [
    { "name": "answer.change", "payload": { "field": "h_val", "value": "0.2" } }
  ]
}

```



### `POST /api/attempts/{attempt_id}/submit`

Фиксирует финальную сдачу решения: проставляет метку времени сдачи `submitted_at = NOW()` и сохраняет финальные ответы:

* **Тело запроса:**
```json
{
  "answers": {
    "initial_m": 10,
    "model_type": "Экспоненциальное: n(z) = n0 * exp(-|z| / h)",
    "h_val": 0.22,
    "n0_val": 200
  }
}

```


* **Ответ `200 OK`:** `{"status": "ok", "submitted_at": "2026-10-04T20:15:00Z"}`

## 2. Административный контур

Все административные маршруты требуют заголовок:
`Authorization: Bearer <ADMIN_TOKEN>`

Контур защищен механизмом Rate Limiter: при 5 неудачных попытках ввода токена в течение минуты IP-адрес блокируется на 15 минут с кодом `429 Too Many Requests`.

### `GET /api/admin/tasks`

Возвращает реестр всех обнаруженных на диске папок задач со статусами валидации и флагами видимости.

### `POST /api/admin/tasks/rescan`

Инициирует повторное чтение директории хранилища без перезапуска контейнеров.

### `POST /api/admin/tasks/upload`

Принимает `multipart/form-data` ZIP-архив задачи, распаковывает в `/data/tasks/<task_id>/` и запускает регистрацию.

### `POST /api/admin/tasks/{task_id}/toggle-visibility`

Инвертирует флаг `"hidden"` в `manifest.json` задачи (скрывает или возвращает в публичный каталог).

### `DELETE /api/admin/tasks/{task_id}`

Безвозвратно удаляет директорию задачи с диска и исключает её из реестра.

### `GET /api/admin/sessions?limit=100`

Возвращает сводку попыток пользователей с открытыми кодами для электронного дневника, длительностью решения, текущим статусом («В процессе» / «Сдано») и количеством событий в логе.

### `GET /api/admin/sessions/{attempt_id}/events`

Возвращает детальную хронологическую цепочку всех кликов и изменений ученика в рамках попытки.

### `GET /api/admin/sessions/{attempt_id}/export/json`

Скачивание полного дампа попытки в виде JSON-файла.

### `GET /api/admin/sessions/export/csv`

Формирует и отдает сводный CSV-файл (UTF-8 BOM для прямого открытия в Excel) со всеми попытками и финальными ответами.

### `GET /api/admin/docs/export/zip`

Скачивание полного архива документации и заготовок шаблонов из директории `docs/`.
