# Спецификация общего модуля `_shared` и библиотеки `AstroPlot` (v1.0.0)

Директория `/app/data/tasks/_shared/` содержит общесистемные фронтенд-библиотеки, стили и шаблоны оформления, доступные всем изолированным виджетам платформы.

---

## 1. Файловая структура и HTTP-раздача

```text
data/tasks/_shared/
├── astroplot.js        # Движок рендеринга графиков, лупы, экстремумов и моста с хостом
└── astroplot.css       # Базовые стили виджета, швейцарская сетка графика и панель инструментов

```

### Маршрутизация в ядре (FastAPI)

Каталог задач целиком монтируется сервером по пути:

```python
app.mount("/static/tasks", StaticFiles(directory=TASKS_DIR), name="tasks_static")

```

Благодаря этому файлы библиотеки доступны из любого виджета по постоянным абсолютным URL:

* `/static/tasks/_shared/astroplot.js`
* `/static/tasks/_shared/astroplot.css`

---

## 2. Подключение в `widget.html`

В секции `<head>` каждого виджета задачи подключаются стили и скрипт:

<head>

  <link rel="stylesheet" href="/static/tasks/_shared/astroplot.css">

## 3. Спецификация класса `AstroPlot`

Класс `AstroPlot` портирован из проверенного компонента `Plot.tsx` первой версии платформы без React-зависимостей. Он реализует математически точный рендеринг SVG-графиков с прилипанием к точкам, оптической лупой для сенсорных экранов, детектором экстремумов и измерением проекций отрезков.

### Конструктор `new AstroPlot(options)`

```javascript
const plot = new AstroPlot({
  container: '#plot-view',        // CSS-селектор или DOM-элемент контейнера (обязательно)
  data: taskData,                 // Исходные данные графика (необязательно, можно вызвать setData позже)
  initialTool: 'cursor',          // Начальный инструмент: 'cursor' | 'loupe' | 'extremum' | 'segment'
  width: 640,                     // Внутренняя ширина viewBox (по умолчанию 640)
  height: 360,                    // Внутренняя высота viewBox (по умолчанию 360)
  paddingLeft: 56,                // Отступ слева под подписи оси Y (по умолчанию 56)
  paddingRight: 14,               // Отступ справа (по умолчанию 14)
  paddingTop: 14,                 // Отступ сверху (по умолчанию 14)
  paddingBottom: 40,              // Отступ снизу под подписи оси X (по умолчанию 40)
  snapRadius: 12,                 // Радиус прилипания курсора к точкам в координатах viewBox (по умолчанию 12)
  extremumWindow: 0.08,           // Ширина окна поиска локального экстремума (доля от размаха оси X, по умолчанию 0.08)
  onReading: ({ reading, pending, extremum }) => { ... }, // Коллбэк перемещения курсора / визира
  onMarksChange: (marks) => { ... }                       // Коллбэк изменения зафиксированных отметок
});

```

### Формат входных данных (`data`)

Объект данных совпадает со структурой, возвращаемой функцией `generate()` генератора задачи:

```json
{
  "axes": {
    "x": {
      "label": "время t, сут",
      "min": 0.0,
      "max": 20.0,
      "tick": 2.0,
      "inverted": false
    },
    "y": {
      "label": "видимая величина m_V",
      "min": 8.0,
      "max": 10.0,
      "tick": 0.2,
      "inverted": true
    }
  },
  "series": [
    {
      "id": "V",
      "label": "Полоса V",
      "marker": "dot",
      "points": [
        [0.15, 8.42],
        [0.45, 8.87]
      ]
    }
  ]
}

```

* `axes.x.inverted` / `axes.y.inverted` — логический флаг инверсии направления оси. При `inverted: true` для оси $Y$ меньшие числовые значения (более яркие звёзды в астрономии) отображаются вверху, а детекция экстремумов автоматически учитывает, что минимум блеска соответствует большему числовому значению.
* `marker` — `'dot'` (отдельные точки) или `'line'` (ломаная линия плотного спектра).

---

### Публичные методы `AstroPlot`

| Метод | Параметры | Описание |
| --- | --- | --- |
| `setData(data)` | `data: object` | Загружает новые оси и серии точек, перерисовывает координатную сетку. |
| `setTool(tool)` | `tool: string` | Переключает активный режим: `'cursor'`, `'loupe'`, `'extremum'`, `'segment'`. |
| `clearMarks()` | — | Очищает все зафиксированные пользователем метки и отрезки. |
| `removeMark(index)` | `index: number` | Удаляет конкретную зафиксированную точку по индексу. |
| `render()` | — | Принудительная перерисовка текущего состояния холста. |

---

### Режимы измерительных инструментов

1. **Визир (`cursor`):**
* Отображает перекрестье пунктирных линий визира под курсором с прилипанием к ближайшей физической точке (в пределах `snapRadius`).
* В коллбэк `onReading` передаётся `{ x, y, series, index }`.


2. **Оптическая лупа (`loupe`):**
* Выводит линзу радиусом 46 px с увеличением 2.5× и вертикальным смещением вверх (на 64 px для мыши и на 78 px для тач-скрина, чтобы палец пользователя не закрывал точку).
* Внутри лупы повторно рендерится координатная сетка и увеличенные маркеры.


3. **Экстремум (`extremum`):**
* Выделяет локальный максимум или минимум в скользящем окне `extremumWindow * (x_max - x_min)`.
* Определяет тип экстремума относительно базовой линии. При клике фиксирует точку с пометкой `#ID max` или `#ID min`.


4. **Отрезок (`segment`):**
* Первый клик фиксирует точку начала (`pending`).
* При перемещении курсора выводится проекция на ось времени с отображением текущей разности $\Delta X$.
* Второй клик замыкает отрезок, рисует толстую проекционную засечку на оси абсцисс и фиксирует метку с вычисленной длиной $\Delta X$.

## 4. Спецификация моста платформы `AstrositeBridge`

Объект `AstrositeBridge` встроен в `astroplot.js` и инкапсулирует протокол общения с родительским фреймом хоста:

### `AstrositeBridge.initAutoResize(targetId = 'widget-root')`

Инициализирует отслеживание высоты контента виджета с демпфером.

* Не допускает бесконечного расширения iframe благодаря измерению физического ограничивающего прямоугольника `getBoundingClientRect().height` контейнера `#widget-root` (вместо растягивающегося `document.body`).
* Отправляет сообщение `ASTROSITE_FRAME_RESIZE` только при изменении высоты более чем на 6 px.

### `AstrositeBridge.sendAnswerChange(answers)`

Отправляет событие `ASTROSITE_ANSWER_CHANGE` на родительский хост для фонового сохранения черновика в базу данных.

### `AstrositeBridge.submitAttempt(answers)`

Отправляет событие `ASTROSITE_SUBMIT_ATTEMPT` на родительский хост для вызова серверной автопроверки и фиксации сдачи работы.

## 5. Спецификация стилей `astroplot.css`

Файл содержит унифицированные стили и CSS-переменные дизайн-системы:

* `--bg`: цвет фона `#ffffff`
* `--card`: цвет карточек и панелей `#f8fafc`
* `--border`: цвет линий и границ `#cbd5e1`
* `--text`: основной текст `#0f172a`
* `--muted`: вспомогательный приглушенный цвет `#64748b`
* `--accent`: цвет акцентов и визира `#d3261f`
* `--primary`: цвет точек и кривых `#2563eb`
* `--success`: цвет успешной сдачи и верных ответов `#16a34a`

Также включает стили панелей `.toolbar`, чипов зафиксированных точек `.mark-chip`, контейнера графика `.plot-container` и баннера подтверждения сдачи `.session-banner`.

# Изменения в существующем `docs/TASK_BUNDLE_SPEC.md`

В документ `docs/TASK_BUNDLE_SPEC.md`[cite: 30] вносится раздел **«Использование общей библиотеки `_shared`»**:

```markdown
## 5. Использование общей библиотеки `_shared`

Для задач, требующих графиков, спектров или фотометрических кривых, не допускается дублирование кода отрисовки осей и лупы внутри `widget.html`. Виджет обязан подключать библиотеку платформы:

```html
<link rel="stylesheet" href="/static/tasks/_shared/astroplot.css">
<script src="/static/tasks/_shared/astroplot.js"></script>

```

Инициализация выполняется в `DOMContentLoaded`:

```javascript
const plot = new AstroPlot({
  container: '#plot-view',
  onReading: ({ reading, pending, extremum }) => {
    // обновление показаний текущих координат
  },
  onMarksChange: (marks) => {
    // обновление списка зафиксированных точек
  }
});

// Автоматический репорт высоты для устранения скроллбаров хоста
AstrositeBridge.initAutoResize('widget-root');

```

При получении `ASTROSITE_INIT_DATA` данные передаются напрямую:

```javascript
plot.setData(event.data.data);

```
