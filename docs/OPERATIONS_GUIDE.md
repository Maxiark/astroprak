# Руководство администратора и преподавателя Astrosite (v1.0.1)

## 1. Управление конфигурацией и токенами

Токен администратора и секреты окружения задаются в файле `infra/.env` хост-машины[cite: 6]:
```bash
ADMIN_TOKEN=сложный_секретный_токен_администратора
POSTGRES_PASSWORD=надежный_пароль_базы_данных
COOKIE_SECURE=0 # Установить 1 при работе через чистый HTTPS

```

Если переменная `ADMIN_TOKEN` не задана в `.env`, по умолчанию используется `dev-admin`.

## 2. Сценарий проверки домашних заданий

1. **Действия ученика:**
   * Открывает задачу, решает её с помощью измерительных инструментов (визир, лупа, экстремумы, отрезки).
   * При закрытии вкладки или смене устройства восстанавливает работу по 32-значному коду через пункт **«Ключ / Код сессии»** $\rightarrow$ **«Восстановить сессию»**[cite: 29].
   * Нажимает кнопку сдачи: система мгновенно проверяет ответ, подсвечивает поля (зелёный/красный цвет) и выводит итоговый балл с указанием эталонов и погрешностей[cite: 25, 26].
   * Копирует 32-значный код сессии и отправляет учителю через электронный журнал[cite: 29].

2. **Действия учителя:**
   * Переходит в `/admin`, открывает вкладку **«Аналитика сессий»**[cite: 29].
   * В строке поиска находит попытку по коду ученика[cite: 29].
   * В колонке **«Статус»** сразу видит оценку: например, `✓ Сдано (9.0 б.)`[cite: 21].
   * Клик по ссылке **«Протокол»** раскрывает карточку проверки каждого поля: введенное число, истинное значение, коридор погрешности и начисленный балл.
   * Кнопка **«📥 Выгрузить все в CSV (Excel)»** выгружает готовую ведомость с оценками для выставления в журнал[cite: 21, 29].

## 3. Добавление, скрытие и удаление задач на лету

### Вариант А: Через веб-интерфейс админки

1. **Загрузка:** Упаковать папку задачи в архив `<task_id>.zip` (в корне архива должны быть `manifest.json`, `widget.html` и опционально `generator.py`). В блоке «Загрузка пакета (.zip)» выбрать файл и нажать «Загрузить на лету».


2. **Скрытие/Показ:** Нажатие кнопки «Скрыть» в таблице выставляет `"hidden": true`, мгновенно убирая задачу из каталога учеников без удаления файлов с сервера. Кнопка «Показать» возвращает её в каталог.


3. **Удаление:** Кнопка «Удалить» с подтверждением диалога физически удаляет папку задачи из тома `/app/data/tasks/`.



### Вариант Б: Через терминал сервера

1. Создать папку задачи:
```bash
mkdir -p data/tasks/my-new-task

```


2. Поместить файлы пакета в директорию.
3. В админ-панели нажать кнопку **«⟳ Пересканировать хранилище»** (или выполнить `POST /api/admin/tasks/rescan`). Перезапуск контейнеров ядра **не требуется**.
